# Agent 企业级项目标准

这一组文档的目标，是把前面 11 章的 Agent 认知，以及第 12 章的企业级 RAG 架构，进一步落成一套企业项目可以使用的交付标准。

它关注的不是“Agent 能不能演示”，而是：

> Agent 能不能被安全地开发、上线、运营、审计、回滚和持续改进。

## 目录

1. [00-企业级项目总览.md](./00-企业级项目总览.md)  
   定义企业级 Agent 项目的成熟度、交付边界和优先级。

2. [01-Agent平台参考架构.md](./01-Agent平台参考架构.md)  
   给出 Agent Runtime、Tool Gateway、Policy Engine、Memory、Eval、Audit 等模块边界。

3. [02-安全合规与威胁模型.md](./02-安全合规与威胁模型.md)  
   将 Agent 风险映射到权限、提示注入、数据泄露、过度代理、审计和合规证据。

4. [03-评估体系与上线准入.md](./03-评估体系与上线准入.md)  
   给出评估集结构、核心指标、上线门槛和回归要求。

5. [04-SLO与Runbook.md](./04-SLO与Runbook.md)  
   定义服务目标、告警、事故响应、回滚和演练要求。

6. [05-交付资产清单与模板.md](./05-交付资产清单与模板.md)  
   整理企业交付时需要的文档、接口、配置、评审和验收资产。

## 最小企业级交付包

如果只选最小集合，建议至少具备：

| 类别 | 必备资产 |
| --- | --- |
| 产品边界 | 场景说明、不适用场景、用户角色、失败代价 |
| 架构 | 模块边界、数据流、控制流、权限流、版本流 |
| 安全 | 威胁模型、权限矩阵、高风险动作审批、审计字段 |
| 评估 | 真实任务样本、回归集、上线准入阈值、评估报告 |
| 运维 | SLO、告警规则、Runbook、回滚方案、事故复盘模板 |
| 工程 | API 契约、配置 schema、测试、CI、部署说明 |

## 和现有章节的关系

- `09-agent-的评估与测试.md` 讲评估思路，本章补上线准入和验收阈值。
- `10-agent-的安全、权限与人机协作.md` 讲安全机制，本章补威胁模型和合规证据。
- `11-agent-的工程化与生产落地.md` 讲工程化原则，本章补 SLO、Runbook 和交付资产。
- `12-rag-企业级架构与落地` 讲 RAG 平台，本章补 Agent 项目整体交付标准。
